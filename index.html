CompCert4Lean: Porting a Verified C Compiler to Lean in Six Weeks with Parallel Coding Agents

See arXiv listing · cs.PL, cs.LO · 2026-11-16

The clearest real-world demonstration yet of a 'software factory': one expert directing a fleet of parallel LLM agents to do months of formal-verification engineering in weeks.

The authors port CompCert 3.17's verified compiler core from Rocq (Coq) to Lean in roughly six weeks, with one human expert orchestrating parallel LLM coding agents rather than hand-translating the proofs. The migration workflow partitions the codebase along its dependency graph, has agents translate definitions and theorems in parallel, then audits the results for faithfulness to the original verified semantics. It's a concrete case study in treating a large, high-assurance engineering project as an assembly line of agent workers with a human supervisor, rather than a single autonomous agent doing everything end to end.

SWE-CoWork: Benchmarking Coding Agents as Digital Employees in Organizations

See arXiv listing · cs.SE, cs.AI · 2026-11-15

Directly tests the 'agent as digital employee inside a software factory' framing, not just isolated coding tasks.

SWE-CoWork introduces a benchmark of 101 development assignments spanning 101 real repositories, 11 programming languages, and 12 application domains, explicitly framed around what a coding agent must do as a member of a software organization: figure out what to build, collaborate with colleagues/stakeholders, and verify that what it delivers is actually correct and complete — not just whether tests pass. It pushes evaluation beyond solo bug-fixing benchmarks toward the organizational, collaborative texture of real software production.

Agent-Native by Design: A Programming Language for Agentic Applications

See arXiv listing · cs.PL, cs.AI, cs.SE · 2026-11-16

Proposes new language-level infrastructure purpose-built for assembling agentic software, i.e. tooling for the factory floor itself.

The paper argues that today's agent frameworks and SDKs force developers to hand-write a lot of glue code to combine LLM calls, workflow structure, application state, and model-guided routing — and that this glue is exactly where bugs and brittleness creep in. It proposes a programming language designed 'agent-native from the ground up,' with first-class constructs for state propagation and model-guided control flow, aiming to make building agentic applications (including agents that themselves write software) a principled language-design problem rather than an afterthought bolted onto general-purpose code.

Beyond Weight Updates: Evolving Agent Harnesses for Domain Specialization

See arXiv listing · cs.AI · 2026-11-19

Reframes 'specializing an agent for a domain' as harness engineering rather than model fine-tuning — relevant to standing up many domain-specific agent factories cheaply.

Domain specialization of LLM agents is usually treated as a weight-update problem: collect trajectories, run RL or SFT, ship a new checkpoint. This paper studies the complementary axis of evolving the agent harness itself — system prompt, tool schemas, and surrounding scaffolding — as the unit of optimization instead of the model weights. That matters for software factories because it suggests you can retarget a generic coding agent to a new domain or codebase by evolving its harness rather than retraining or fine-tuning, which is far cheaper and faster to iterate on.

Values Shape What Self-Improving Coding Agents Build

See arXiv listing · cs.AI, cs.MA · 2026-11-17

A pointed alignment question for autonomous software factories: once agents self-improve with little oversight, what governs *how* they build, not just *what*?

Self-improving coding agents are typically optimized for the end results they produce, with little attention paid to how they get there, especially on open-ended tasks where designers have limited levers to shape process rather than outcome. This paper tests whether inserting a short value statement into an agent's persona/instructions measurably changes what a self-improving coding agent chooses to build and how it works — a small intervention with large implications for anyone trying to run a largely autonomous, self-improving software production pipeline safely.
